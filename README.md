# Excel Batch Renamer

面向离线 Windows 7 流水线的 Excel 批量文件整理工具。

## 功能

- 根据固定 `.xlsx` 模板创建 `001——` 或 `001——文件夹名称`；
- 根据后续整理完成的 `.xlsx` 补全或更新文件夹名称；
- 按图片任务表的单个工作表和页次范围重命名一个文件夹中的直属 JPG；
- 遍历所有数字工作表，自动匹配父目录下序号相同的多个文件夹并批量重命名 JPG；
- 批量模式直接跳过空的数字工作表，并在完成结果中列出跳过项；
- 两种图片任务改名后，按文件题名自动把同一文件的图片生成 PDF，原 JPG 保留；
- 同一窗口提供四个相互独立的 Tkinter 标签页。

## 编码前缀文件夹

“重命名文件夹”也识别 `I74-6-256——` 这类源目录：取最后一个半角 `-` 后的
数字 `256`，与任务表的 `序号=256` 匹配，按该行 `文件夹名称` 输出
`256——验收文件`。创建目录的规则不变；空名称行仍保留当前文件夹。
重命名任务的序号允许不连续，因此 Excel 可以只填写序号 256 这一行，不需要
补齐 1～255；只有表格列出的序号参与匹配，其他直属文件夹保持不变。

图片任务的工作表仍命名为 `256`，既可对应改名前的 `I74-6-256——`，也可对应
改名后的 `256——验收文件`。图片任务只处理 JPG/PDF，不执行文件夹改名。
同一父目录下若有多个文件夹提取出相同序号，仍先提示重号并停止。

## 自动生成 PDF

沿用“重命名图片”和“批量重命名图片”标签页，点击一次“直接执行”即可完成改名和 PDF 生成，不增加页面或开关。

例如 `文件题名=验收文件`、`页次=6-10`，会先得到 `006验收文件.jpg` 至 `010验收文件.jpg`，再在该图片文件夹内生成 **5 页的 `验收文件.pdf`**。每张 JPG 对应一页，按页码升序排列，不把多个项目文件夹合成一个 PDF。

本版本采用以下默认处理规则：

- 同一工作表内相同文件题名的图片合成一个 PDF，即使题名分布在不相邻的数据行；
- 重跑时按当前 Excel 和图片重新生成，覆盖当前同名 PDF；即使图片名称没有变化，也会生成 PDF；
- 题名变更后留下的旧 PDF 和其他文件原样保留，不自动清理；
- 改名前校验整次任务的绑定、图片页码、JPEG 内容和 PDF 路径冲突，批量模式先校验全部文件夹；
- 执行中失败立即停止并显示已改名、未变化和已生成 PDF 数量，不撤销已完成的操作；当前 PDF 完整写入后才替换已有同名 PDF。

PDF 保留原 JPEG 数据，不重新压缩；页面按图片尺寸和 DPI 排版，并遵循 EXIF 旋转/镜像方向，不强制使用 A4。具体规则见 [`功能需求`](docs/requirements/functional-requirements.md)。


## 便携构建

项目使用 Python 3.8.10、PyInstaller 4.10 `onedir`，分别生成带控制台测试版和无控制台正式版；PDF 依赖 ReportLab 3.6.13 和 Pillow 9.5.0 随完整目录交付，客户机无需安装新环境。构建流程与兼容性边界见 [`docs/delivery/portable-build.md`](docs/delivery/portable-build.md)。

项目协作规则、Git 分支流程和自动收尾授权见 [`AGENTS.md`](AGENTS.md)。
