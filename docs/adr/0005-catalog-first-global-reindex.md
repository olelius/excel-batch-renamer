# ADR 0005：文件目录在前、图纸目录在后的全局编排

日期：2026-09-16。状态：本次实现采用。

## 背景

原流程把档号末段直接作为文件夹和工作表编号。当文字档案中间穿插图纸档案时，
物理档号顺序不能表达交付要求的“文字在前、图纸在后”。工作表标签位置也可能无序。

## 决定

批量流程同时读取文件目录和图纸目录两个工作簿，以工作表名称作为档号；分别按档号
自然顺序生成集合，先为文件目录分配新序号，再为图纸目录接续分配。生成独立映射表，
后续工作表、文件夹、JPG 和 PDF 都以该映射为唯一依据，不依赖原标签位置。

文件夹统一使用 `新序号-文件夹名称`。每个文件夹中的 JPG 按现有页码顺序从 001
独立重新起号，再执行题名改名和 PDF 生成。映射工作簿放在父目录，两个目录工作簿
原地更新；重复执行通过映射表恢复原档号关系。

## 取舍

把两个类别放入一个全局序列，可稳定满足交付排序并避免图纸穿插。代价是批量流程从
单工作簿操作升级为跨两个工作簿、文件夹和图片的多阶段执行；运行期文件占用仍可能
在部分阶段完成后中断，沿用项目“不自动回滚已完成操作”的既有边界。
