# ADR 0007：每条目录记录独立生成 PDF

日期：2026-10-10。状态：用户已确认，采用。替代 ADR 0004 的跨行同题名合并默认。

## 背景与决定

用户提供的五条目录记录中，01/04 同题名、03/05 同题名；旧版只生成三份 PDF。
用户确认应生成五份：每条记录自己的页次范围对应一个 PDF，同题名也不跨行合并。
这不是上游数据错误，无需用户改题名或人工加后缀。

## 实现

复用既有页次推导，在每张图片计划中保留所属记录的 `record_start_page`。用记录起始页
分组，而不是题名；不能只按连续同题名图片分段，因为相邻同题名记录也必须独立。
预检及执行共用逐行分组函数，各组按页码升序写入。单文件夹、批量图片及双目录编排
通过同一应用服务生效，不新增 UI、依赖或复杂恢复模块。

PDF 名称仍为三位起始页直接拼接题名；JPG 名称、页次推导、JPEG 原图嵌入、EXIF/DPI、
重跑覆盖、临时文件完整写入后替换、失败停止不回滚等规则不变。
旧版同名合并 PDF 在重跑时覆盖为当前记录内容，并新增后续同题名记录的 PDF；
不自动清理无关/旧题名 PDF。

## 验证范围

- 用户示例五条记录对应五份 PDF，页数为 4/7/8/7/10；检查真实页序及 JPG 原字节。
- 相邻/不相邻的同题名记录分别独立；旧合并结果重跑、JPG 无变更时仍生成。
- 后续同题名记录的 PDF 路径冲突在任何改名前拦截，包含批量后续文件夹。
- 双目录编排及重复执行沿用相同行边界；便携冻结自检实际创建同题名相邻两行并生成两份 PDF。
