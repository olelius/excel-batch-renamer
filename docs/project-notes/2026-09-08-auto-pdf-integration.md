# 2026-09-08 自动 PDF 功能：应用服务与 UI 协作记录

## 本子任务范围

- 修改单文件夹和批量图片应用服务、两个现有图片标签页及对应测试。
- PDF 编码、原子写入、依赖和打包由主代理集成；本子任务未切分支或提交 Git。

## 已完成实现

- 图片计划保留本次 Excel 的 `file_title`，重命名结束后按题名汇总并按页码升序生成 PDF；不为 PDF 再读 Excel，不读取历史执行记录。
- 同题名的非相邻行合并为一个 PDF；题名仅大小写不同而产生 Windows 同名歧义时，首次图片改名前报错。
- PDF 位于原图片文件夹，JPG 保留；重复执行更新同名 PDF，旧题名 PDF 不自动删除。
- 单目录和整批任务建计划时校验源 JPG 与 PDF 目标目录占用，后续文件夹的已知输入错误也会阻止整批改名。
- 单目录结果与批量结果增加 `generated_pdfs`；PDF 失败携带改名、未变化和 PDF 已完成数量，批量立即停止后续文件夹，不回滚已完成项。
- 原两个标签页显示 PDF 完成数量与存放位置；沿用底部状态区处理错误，不新增页面、开关或弹窗。

## 验证安排

- 已将正常图片测试样本替换为真实 JPEG，加入 `6-10` 五页 PDF、当前页次重跑、同题名汇总、整批前置阻断与失败统计的服务及 UI 用例。
- 用户要求避免过多测试、检验和审查；本子任务未单独运行测试，由主代理完成一次集成验证并记录实际结果。
- 真实离线 Windows 7 SP1 x64 验证仍留给目标机测试。
