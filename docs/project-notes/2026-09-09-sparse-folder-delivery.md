# v0.3.2 稀疏文件夹重命名任务

## 问题与修复

编码来源文件夹 `I74-6-256——` 的真实业务只需任务表一行：
`序号=256`、`文件夹名称=验收文件`。v0.3.1 错误地复用了创建文件夹任务的
1 至 n 连续序号规则，因而要求补齐 1 至 255 及对应目录。

本次将两个任务的规则分离：

- 创建文件夹继续要求序号从 1 连续到 n；
- 重命名文件夹接受任意不重复正整数序号；
- 只匹配表格列出的序号，未列出的直属文件夹不参与本次任务；
- 缺少对应目录、一个序号匹配多个目录、重复表格序号及目标占用仍在改名前拦截；
- 编码前缀提取、空名称保留、图片任务和自动 PDF 行为保持不变。

## 验证与打包

- 沿用原测试数量，仅修改既有连续序号用例为稀疏序号成功用例；没有扩展测试矩阵。
- 一轮完整回归：96 项通过，0.827 秒。
- 真实 XLSX 仅含序号 256，验证 `I74-6-256——` 改名为
  `256——验收文件`、内部内容保留及重复执行无变化。
- 在既有稀疏序号用例中补充未列出目录保持不变的断言后，仅定向复跑
  `test_rename_folders` 13 项，全部通过。
- `compileall`、`pip check`、`git diff --check` 通过。
- 双 onedir 构建及便携运行、发布 ZIP 解压自检通过；测试版和正式版均为
  994 个文件，分别为 29,712,523 与 29,714,051 字节。
- 本地日志：`.artifacts/verify-sparse-folder-v0.3.2.log`、
  `.artifacts/build-sparse-folder-v0.3.2.log`。
