# v0.4.2 档号名称表驱动文件夹命名

## 修复

v0.4.1 从原文件夹尾部取得名称；原文件夹只有档号时会生成 `001-`。本版在
“批量整理档案”增加第三个工作簿输入“档号名称 Excel”。该表必须只有一个工作表，
第一行含唯一的 `档号`、`文件夹名称` 两列，并明确不接受 `序号` 列；新序号仍由
程序按文件目录在前、图纸目录在后的规则生成。

文件夹名称现在完全按档号从该表读取，不再从现有文件夹尾部猜测。前版已生成
`001-` 空名称文件夹时，程序通过已有档号映射表还原档号，再补全为 `001-题名`。
输出的 `档号与新序号对应表.xlsx` 继续保留新序号，作为程序生成的结果，不是输入表。
