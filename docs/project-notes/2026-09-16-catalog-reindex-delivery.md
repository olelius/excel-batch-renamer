# v0.4.0 文件目录与图纸目录全局编排

## 实现结果

第四个标签页升级为“批量整理档案”，输入文件目录 Excel、图纸目录 Excel 和父目录。
两个工作簿的工作表名称作为档号；程序不依赖原标签位置，而是分别按档号自然顺序
生成映射。文件目录先从 001 编号，图纸目录接续编号。

执行顺序为：写出 `档号与新序号对应表.xlsx`、按档号更新两个工作簿的工作表名称、
把直属文件夹改为 `新序号-文件夹名称`、把每个文件夹内 JPG 按原页码顺序从 001
独立起号，最后复用题名和 PDF 流程。工作簿原地更新；再次执行通过映射表恢复档号。

旧式创建文件夹、表格重命名文件夹及单文件夹图片任务保留。新编排文件夹的
`001-名称` 前缀已加入共享序号解析，供图片绑定使用。

## 验证范围

按用户要求控制验证规模，只保留一个代表性集成场景：文件目录和图纸目录各两个
乱序档号，验证档号自然排序、文件目录优先、图纸接续、映射表、工作表顺序、
文件夹连字符命名、每卷 JPG 从 001 起号及 PDF 页数。随后执行一次完整回归：
96 项通过，0.818 秒；`compileall`、`pip check`、`git diff --check` 通过。

双 onedir 构建及便携运行、发布 ZIP 解压自检通过；测试版和正式版均为 994 个文件，
分别为 29,719,520 与 29,721,061 字节。日志位于：
