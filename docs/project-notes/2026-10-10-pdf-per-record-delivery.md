# v0.5.1 逐行独立 PDF 交付

日期：2026-10-10。任务分支：`agent/pdf-per-record`。

## 原因与修正

用户目录有五条记录，但 01/04 和 03/05 分别同题名。原默认以题名归组，导致只生成三份
合并 PDF。用户已确认改为每条目录记录按自己的页次范围独立生成，不允许同题名跨行合并。

图片计划新增 `record_start_page`，复用既有页次推导保留记录边界；预检和执行共用逐行
分组函数。单文件夹、批量图片和双目录编排都沿用该服务。JPG 名称和 PDF 起始页前缀不变，
无新 UI 或依赖。相邻同题名记录也独立，不用连续同题名分段代替行边界。
详见 [ADR 0007](../adr/0007-pdf-per-directory-record.md)。

- 正式便携目录：`.artifacts/portable/ExcelBatchRenamer`，必须复制整个目录。

合并 PDF 会覆盖为当前行内容，020 和 027 等后续行将独立补出；其他历史 PDF 不自动删除。
