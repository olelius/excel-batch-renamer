Excel 批量文件整理工具
========================

一、交付方式

必须复制整个 ExcelBatchRenamer 文件夹，不能只复制其中的 EXE。
客户机不需要安装 Python、Excel、WPS、Java 或 .NET。

二、启动

正式版：双击 ExcelBatchRenamer.exe，只显示操作界面。
测试版：双击 ExcelBatchRenamer-Test.exe，同时显示 CMD 控制台和操作界面。

三、操作

1. 创建文件夹
   分别选择固定模板 .xlsx 和本次任务文件夹，点击“直接执行”。

2. 重命名文件夹
   分别选择固定模板 .xlsx 和本次任务文件夹，点击“直接执行”。
   支持 I74-6-256—— 这类源文件夹，取末段 256 与 Excel 序号对应。
   若该行文件夹名称是“验收文件”，结果为 256——验收文件。
   标准三位数字前缀继续兼容；空名称行保留当前文件夹。

3. 重命名图片
   依次选择图片任务 .xlsx、任务文件夹和工作表。
   选择任务文件夹后会自动选择编号对应的工作表，也可以手动修改。
   点击“直接执行”时仍会校验数字工作表名称与文件夹提取出的编号。
   工作表 256 同时适用于 I74-6-256—— 和 256——验收文件，图片任务不改文件夹名。
   改名后自动按文件题名生成 PDF，保存在原图片文件夹，JPG 保留。

4. 批量重命名图片
   依次选择图片任务 .xlsx 和包含多个项目文件夹的父文件夹。
   程序自动遍历全部数字工作表，匹配父文件夹下提取出的编号相同的直属文件夹。
   全部匹配和图片计划验证通过后才开始执行；非数字工作表和无对应工作表的其他文件夹不处理。
   空的数字工作表直接跳过，不要求存在对应文件夹；完成结果会显示跳过数量和工作表名称。
   每个项目文件夹改名后自动生成对应 PDF，不跨文件夹合并。

所有成功数量或失败原因都显示在当前标签页底部，不弹确认框。
图片任务同时显示已改名、未变化和已生成 PDF 数量，无需另开页面或单独执行。

示例：“文件题名”为“验收文件”，“页次”为“6-10”，自动将第 6 至 10 页
改名为 006验收文件.jpg 至 010验收文件.jpg，并生成五页“验收文件.pdf”。
同一工作表内相同题名的图片按页码升序归入一个 PDF，即使题名位于不相邻行。
再次执行时会重新生成并覆盖当前同名 PDF，即使图片名称未变化也会生成。
题名变更后遗留的旧 PDF 和其他文件保留，不自动清理。
图片按原尺寸、DPI 和 EXIF 方向生成 PDF，不强制 A4，不重新压缩 JPG。

四、输入约定

- 文件格式固定为 .xlsx。
- 文件夹模板表头在第一行，数据从第二行开始。
- 图片任务表表头在第三行，数据从第四行开始，前两行内容忽略。
- 表头文字中即使带普通空格、全角空格或制表符也能识别。
- 只忽略表头中的空白，数据内容中的空格会原样保留。
- 文件夹任务表只有一个工作表，包含“序号”“文件夹名称”。
- 图片任务表的目标工作表包含“序号”“文件题名”“页次”。
- 图片只处理任务文件夹直属的 JPG，不处理子文件夹。
- 改名前验证 JPG 内容和 PDF 路径；批量任务先验证全部文件夹。
- PDF 目标被同名目录占用、或不同题名仅大小写不同造成同名歧义时，停止并提示。
- 发生文件占用或权限错误时立即停止，不自动回滚。
- 每个 PDF 完整写入后才替换同名目标；失败保留原有 PDF 和此前已完成结果。

五、兼容性

目标系统：64 位 Windows 7 旗舰版 SP1。
当前目录由开发机完成构建与运行验证；真实 Windows 7 最终兼容性以客户机测试结果为准。
